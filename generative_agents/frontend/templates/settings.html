⚙ LLM 設定

呢度設定故事用嘅語言模型。ollama 係本機免費（要裝咗 Ollama 先）； openai 係任何 OpenAI 兼容 API（DeepSeek、Kimi、OpenAI 等），要填 API key。 改完之後新開嘅故事先生效，行緊嘅故事唔受影響。

角色思考 LLM

驅動每個角色嘅日常諗法、計劃、對白。用量最大，平價模型都做得唔錯。

記憶檢索 Embedding

角色「諗返起」舊事用。如果用 ollama，base_url 留意係 唔加 /v1 嗰個（例如 http://127.0.0.1:11434）。

GM / 故事回顧 LLM

每回合寫摘要、出分支選項、寫終章。用呢刻負擔得起最好嘅模型，回合先 call 一次。

遊戲節奏

每回合行幾多個模擬步。步數越少回合越快（推薦 3-6；每步大約 1-2 分鐘，視乎角色數目同模型速度）。
